경사하강법의 기하학: 보폭, 조건수, 가속과 확률적 탐색

접선 기울기 \(-\nabla f\)와 \(L\)-평활성 이차 상계, 타원 계곡 조건수 \(\kappa=L/\mu\), Ridge 완화 · Momentum · Newton–Raphson 및 Mini-batch SGD

고차원 추정과 머신러닝에서 목적함수를 최소화하는 가장 기본적인 반복 규칙은 현재 위치에서 가장 가파르게 내려가는 방향 \(-\nabla f(\theta_k)\)으로 한 걸음 이동하는 것이다. 왜 그 방향이 등고선에 수직인지, 보폭 \(\eta\)가 \(1/L\)과 \(2/L\)을 지날 때 왜 진동·발산하는지, 상관된 설명변수가 만드는 좁은 협곡(\(\kappa = L/\mu \gg 1\))을 Ridge · Momentum · Newton이 어떻게 극복하는지, 그리고 확률적 미니배치 잡음(SGD)이 볼록 수렴 바닥과 비볼록 안장점 탈출에 어떤 역할을 하는지 단계별로 확인한다.

01기본 원리: 접선 기울기 \(-\nabla f\), \(L\)-이차 상계, 보폭 \(\eta\)의 4가지 양상

미분가능한 목적함수 \(f(\theta)\)의 최솟값은 기울기가 \(0\)이 되는 정류점(\(\nabla f(\theta^*)=0\))에 있다. 닫힌형 해가 없거나 역행렬 계산이 너무 비쌀 때, 경사하강법(Gradient Descent)은 현재 점 \(\theta_k\)에서의 1차 테일러 근사 + 최대 곡률 \(L\)에 의한 이차 상계 \(q_L(\theta)\)를 매 단계 최소화하는 방식으로 작동한다: \(\theta_{k+1} = \theta_k - \eta \nabla f(\theta_k)\).

음의 그래디언트 · 최급강하
\[ \min_{\|u\|_2=1} \nabla f(\theta_k)^\top u = -\|\nabla f(\theta_k)\|_2 \]

등고선 접선(\(\nabla f^\top v = 0\))에 수직(\(90^\circ\))이며 국소적으로 함숫값을 가장 빠르게 낮춘다.

\(L\)-Smoothness 상계 & \(\eta=1/L\)
\[ f(\theta) \le f(\theta_k) + \nabla f(\theta_k)^\top(\theta-\theta_k) + \frac{L}{2}\|\theta-\theta_k\|_2^2 \]

위 이차 대리함수 \(q_L(\theta)\)의 최솟점이 정확히 \(\theta_k - \tfrac{1}{L}\nabla f(\theta_k)\)다.

안정성 임곗값 \(0 < \eta < 2/L\)
\[ \theta_k = (1 - \eta L)^k \theta_0 \quad\text{(on } f(\theta)=\tfrac{L}{2}\theta^2\text{)} \]

\(\eta \ll 1/L\)은 느린 단조 수렴, \(1/L < \eta < 2/L\)은 반대쪽 사면을 오가는 감쇠 진동, \(\eta > 2/L\)은 폭발적 발산을 낳는다.

02타원 계곡과 조건수 \(\kappa = L/\mu\): Ridge 완화 vs Momentum & Newton

회귀모형 \(\min_\theta \tfrac{1}{2n}\|Y-X\theta\|_2^2\)에서 설명변수가 강하게 상관되면 헤시안 \(H = \tfrac{1}{n}X^\top X\)의 최대·최소 고유값 비율인 조건수 \(\kappa = L/\mu\)가 급증하여 등고선이 좁고 긴 타원 협곡으로 찌그러진다(ML Ch 05 §5.5 참조). 이때 \(-\nabla f\)는 긴 협곡 바닥이 아닌 가파른 양쪽 벽을 향하므로 경사하강법은 양벽을 오가는 심한 지그재그에 갇힌다.

Conditioning, Momentum & Preconditioning Formulas
\[ \text{GD 선형수렴률: } \|\theta_k - \theta^*\|_2 \le \Bigl(\frac{\kappa - 1}{\kappa + 1}\Bigr)^k \|\theta_0 - \theta^*\|_2, \qquad \text{Ridge 조건수: } \kappa(\lambda) = \frac{d_{\max} + \lambda}{d_{\min} + \lambda} \downarrow \] \[ \text{Heavy-Ball Momentum: } v_{k+1} = \beta v_k + \nabla f(\theta_k),\; \theta_{k+1} = \theta_k - \eta v_{k+1} \qquad\big|\qquad \text{Newton: } \theta_{k+1} = \theta_k - H(\theta_k)^{-1}\nabla f(\theta_k) \]
Ridge 벌점 \(\lambda\)와 주의 5.14

\(+\tfrac{\lambda}{2}\|\theta\|_2^2\)는 헤시안에 \(\lambda I\)를 더해 조건수 \(\kappa(\lambda)\)를 낮추고 수치 수렴을 빠르게 만든다. 그러나 최적점 자체를 원점 쪽으로 끌어당겨(\(\hat{\theta}_\lambda^{\mathrm{Ridge}} \neq \hat{\theta}^{\mathrm{OLS}}\)) 추정 편향을 도입하므로 수치적 수렴 속도와 통계적 일치성은 구별해야 한다.

Momentum 관성 vs Newton 곡률 백색화

Momentum은 벽을 왕복하는 수직 성분 기울기를 부호 상쇄시키고 계곡 방향 관성을 축적한다. 계량 Ch 05 §5.19 Newton–Raphson은 역헤시안 \(H^{-1}\)을 곱해 타원 좌표를 원형으로 되돌려 이차형식을 단 1스텝에 도달한다.

03확률적 경사하강법(Mini-batch SGD)과 비볼록 안장점 탈출

표본 크기 \(n\)이 매우 클 때 매 스텝 전체 평균 기울기 \(\nabla Q_n(\theta) = \tfrac{1}{n}\sum_{i=1}^n \nabla \ell_i(\theta)\)를 계산하는 대신, 무작위 미니배치 \(B_k \subset \{1,\dots,n\}\)만 뽑아 불편추정 기울기 \(g_k = \tfrac{1}{|B_k|}\sum_{i\in B_k}\nabla \ell_i(\theta_k)\)로 업데이트하면 스텝당 계산비용이 \(O(n)\)에서 \(O(B)\)로 줄어든다. 동시에 배치 잡음 \(\xi_k = g_k - \nabla Q_n(\theta_k)\) (\(\operatorname{Var}(\xi_k) \propto \sigma^2 / B\))는 고정 보폭 아래에서는 최솟점 주변 잡음 공(noise ball)에 머무르지만, 비볼록 지형에서는 안장점(saddle point) 탈출의 원동력이 된다.

미니배치 분산 vs 학습률 스케줄
\[ \mathbb{E}[g_k \mid \theta_k] = \nabla Q_n(\theta_k),\qquad \mathbb{E}\|g_k - \nabla Q_n(\theta_k)\|_2^2 \propto \frac{\sigma^2}{B} \]

고정 학습률 \(\eta\)는 \(\eta\sigma^2/B\) 수준 오차 바닥에 머무르고, Robbins–Monro 감소 스케줄(\(\eta_k \propto k^{-1/2}\), \(\sum \eta_k=\infty,\;\sum \eta_k^2<\infty\))이 점근 수렴을 복원한다.

비볼록 지형: 안장점과 국소 최솟값
\[ \nabla f(\theta_s)=0,\quad \lambda_{\min}\bigl(\nabla^2 f(\theta_s)\bigr) < 0 \]

고차원 신경망·비선형 모형에는 극소점보다 안장점이 훨씬 많다. 순수 결정론적 GD는 안정 다양체(stable manifold) 위 출발 시 멈추지만, 확률적 잡음 \(\xi_k\)와 관성이 탈출을 돕는다.
