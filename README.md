## ✏️ 내 정보 수정 가이드

1. `index.html` 파일을 열어 이메일 주소(`your-email@uos.ac.kr`) 및 세부 연구 소개를 편집할 수 있습니다.
2. `assets/avatar.svg` 대신 본인의 실제 사진을 `assets/profile.jpg`로 저장하고 `index.html`의 프로필 이미지 경로를 변경할 수 있습니다.
3. 로컬에서 `index.html`을 더블클릭하면 오프라인 브라우저에서 즉시 렌더링된 모습을 확인하실 수 있습니다.
